Public API types, metadata and wire schemas are maintained in the SDK repository. Runtime implementation and native behavior tests belong here. Documentation schema snapshots are generated by `scripts/sync-plugin-sdk-contracts.py`; do not independently edit them. Marketplace source/release instructions belong to the Marketplace.

For contributors and coding agents: explicit current user decisions and tested code establish scope. The native API guide defines implemented contracts; the architecture design also contains future proposals. `sdk-design/` holds the full historical candidate declarations and source inventory, not a package API export. `PluginSystemPlan`, signing research, and VSCodeCompatibility/VSCodePersistence describe earlier plans or bounded experiments. They do not reinstate a VS Code compatibility objective or require signing for development.

Before committing contract changes, validate SDK types/templates, shared wire fixtures and the real native behavior affected by the change. `git diff --check` and link checks accompany documentation edits. Do not publish a new SDK pin before its package and host behavior are verified.
