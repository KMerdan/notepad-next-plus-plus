# Download and install Notepad Next ++

Download [Notepad Next ++ 0.15.1](https://github.com/KMerdan/notepad-next-plus-plus/releases/tag/v0.15.1) from the fork's GitHub Releases page. Source archives generated by GitHub are not application packages. Pick an asset matching your operating system and processor.

| Platform | Release asset | Install |
| --- | --- | --- |
| macOS Apple Silicon, macOS 14+ | [macos-arm64.dmg](https://github.com/KMerdan/notepad-next-plus-plus/releases/download/v0.15.1/NotepadNextPlusPlus-0.15.1-macos-arm64.dmg) | Open the disk image and drag `NotepadNextPlusPlus.app` into Applications. |
| macOS Intel, macOS 14+ | [macos-x86_64.dmg](https://github.com/KMerdan/notepad-next-plus-plus/releases/download/v0.15.1/NotepadNextPlusPlus-0.15.1-macos-x86_64.dmg) | Same process, using the Intel image. |
| Windows x86-64 | [windows-x86_64-installer.exe](https://github.com/KMerdan/notepad-next-plus-plus/releases/download/v0.15.1/NotepadNextPlusPlus-0.15.1-windows-x86_64-installer.exe) | Run the installer. |
| Windows x86-64 portable | [windows-x86_64.zip](https://github.com/KMerdan/notepad-next-plus-plus/releases/download/v0.15.1/NotepadNextPlusPlus-0.15.1-windows-x86_64.zip) | Extract the whole archive; run `NotepadNextPlusPlus.exe`. Keep the `plugins` directory beside it. |
| Linux x86-64, Ubuntu 24.04 or newer compatible glibc | [linux-x86_64.AppImage](https://github.com/KMerdan/notepad-next-plus-plus/releases/download/v0.15.1/NotepadNextPlusPlus-0.15.1-linux-x86_64.AppImage) | Make executable and launch. If FUSE is unavailable, use `--appimage-extract-and-run`. |

Windows also requires the Microsoft Visual C++ runtime. The ZIP includes `vc_redist.x64.exe`; the application installer places the same file in its installation folder. Run that runtime installer once before launching the app if the runtime is missing. This is the compiler runtime distribution used by [Qt’s Windows deployment tool](https://doc.qt.io/qt-6.10/windows-deployment.html).

All five packages include the controlled Node 24 runtime, Qt WebEngine panels, plugin host and third-party notices. No system Node/npm is required to use installed plugins. Download [SHA256SUMS](https://github.com/KMerdan/notepad-next-plus-plus/releases/download/v0.15.1/SHA256SUMS) from the same release and verify your file before installing (`shasum -a 256` on macOS, `sha256sum` on Linux, `Get-FileHash -Algorithm SHA256` on Windows).

These personal macOS builds use ad-hoc signatures, without Apple notarization. macOS may require approval in System Settings → Privacy & Security before the first launch. No Developer ID or notary credentials are required for local builds or this release workflow.

## Homebrew on macOS

The application's repository also serves as the tap; there is no fourth source repository. Its `Casks/notepad-next-plus-plus.rb` pins architecture-specific DMG hashes from a verified published release.

```sh
brew tap KMerdan/notepad-next-plus-plus https://github.com/KMerdan/notepad-next-plus-plus.git
brew install --cask KMerdan/notepad-next-plus-plus/notepad-next-plus-plus
```

Later updates:

```sh
brew update
brew upgrade --cask KMerdan/notepad-next-plus-plus/notepad-next-plus-plus
```

The Cask supports macOS, with separate Apple Silicon/Intel downloads. Linux and Windows use the Release assets above. The commands use a fully qualified Cask name following Homebrew's [custom tap convention](https://docs.brew.sh/Taps.html).

## Install plugins

In **Plugins → Plugin Manager → Add Source…**, register `https://github.com/KMerdan/notepadnext-plugin-marketplace` with an empty Git ref. Discover lists Markdown Preview and HTML Preview. Choose Install, review permissions, then enable in Installed. Refresh Catalog and use Update to fetch a newer release; open panels restore after a successful update.

## Release maintenance

`.github/workflows/build.yml` validates and packages four current plugin-enabled targets (two macOS architectures, Windows x86-64 and Linux x86-64). Tag `v<application-version>` from an accepted main commit, matching `CMakeLists.txt`. The workflow stages five independently named assets, checks runtime/WebEngine closure, generates SHA-256 checksums and creates a draft. Verify its asset set before publishing. Update the Homebrew Cask with verified DMG hashes after publication. Existing version assets must not be replaced.
